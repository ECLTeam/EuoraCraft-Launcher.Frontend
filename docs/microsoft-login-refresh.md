# 微软登录反馈与账户同步修复

## 问题

登录完成后的普通账户加载复用了 ready 缓存，账户列表与当前账户未及时更新。
登录进度已经由后端推送，但界面只显示通用等待文案；半透明弹窗还会透出背景空状态。

## 实施

1. 在共享账户 Store 中，微软即时完成与异步完成均强制刷新账户列表和当前账户。
2. 强制刷新遇到旧请求尚未完成时，合并为后续刷新，不让旧快照覆盖登录结果。
   外置登录的账户变更也遵循相同的刷新规则。
3. 登录启动返回进度时继续展示真实进度；处理启动响应之前到达的状态通知。
4. 将微软登录弹窗提取为独立组件，保留父子弹窗关系、复制代码、浏览器授权与取消操作。
5. 明确区分等待浏览器授权、读取档案、保存账户、错误状态；使用当前主题的半透明表面和模糊层。
6. 同步六种语言文案。

## 验证

- 回归测试先复现已加载缓存、并发旧请求、即时完成和异步完成后的账户缺失。
- 组件测试验证阶段文案、授权码、错误与取消事件。
- 执行 pnpm check、pnpm build。
- 以独立桌面验收实例和模拟登录响应，验证登录后账户管理与首页立即显示账户、关闭与焦点行为。
- 不使用真实凭据，桌面验收采用模拟 Microsoft 登录响应；提交前端及主仓库指针，不推送远端。
